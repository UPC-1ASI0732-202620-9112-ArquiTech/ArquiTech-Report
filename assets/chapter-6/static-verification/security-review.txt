INSPECCION ESTATICA DE CODIGO

SQL Injection
- Backend usa JpaRepository y seis consultas JPQL con parametros nombrados (:id, :projectId). No se hallaron JdbcTemplate, EntityManager, createQuery o consultas nativas construidas por concatenacion.
- Resultado: no se confirmo SQL Injection en el alcance inspeccionado. Esto no sustituye pruebas SAST/DAST.

XSS
- Frontend Web y Landing: busqueda de [innerHTML], innerHTML, DomSanitizer, bypassSecurityTrust*, document.write, eval y new Function sin coincidencias en src/public.
- Riesgo confirmado de dependencias: npm audit reporta avisos XSS en las versiones Angular instaladas y en DOMPurify transitivo de Web.
- Resultado: no se confirmo un sink XSS propio en el codigo; las dependencias vulnerables requieren actualizacion y pruebas de regresion.

Autenticacion, autorizacion y JWT
- Backend: Spring Security stateless, rutas de autenticacion publicas, escritura restringida a SUPERVISOR, @PreAuthorize en servicios de comando, JWT firmado con secreto inyectado y contrasenas con BCrypt.
- Backend: 111 coincidencias de anotaciones Bean Validation y @Valid; los controladores aplican @Valid. SignIn/SignUp redactan password en toString.
- Frontend Web: el JWT se persiste en localStorage. Es una advertencia potencial: un XSS exitoso podria leerlo; no constituye por si solo una explotacion confirmada.
- Frontend Mobile: el JWT se almacena con flutter_secure_storage y SharedPreferences queda reservado para preferencias no sensibles en el codigo inspeccionado.

Secretos
- No se hallaron archivos .env, PEM, JKS, P12, keystore o credenciales con nombres sensibles entre los archivos rastreados.
- application.properties de produccion del Backend usa placeholders de entorno para URL, usuario, password y secreto JWT.
- Los valores literales encontrados en src/test/resources son datos aislados de prueba; no se transcriben.
- Limitacion: Gitleaks y detectores de entropia no estaban instalados; la busqueda por patrones no acredita ausencia absoluta de secretos.

DEPENDENCIAS SIN AUDITORIA CONCLUYENTE
- Backend: el pom no configura un escaner de CVE y OWASP Dependency-Check no estaba instalado; no se declara el arbol Maven como libre de vulnerabilidades.
- Mobile: flutter analyze informo 32 paquetes con versiones mas recientes incompatibles con las restricciones, pero ese aviso no es una auditoria de CVE. No se asigna estado de seguridad satisfactorio.
